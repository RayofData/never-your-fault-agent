# Never Your Fault

**Never Your Fault** is a League of Legends tilt support agent that always believes the player played well.

The agent is designed to defend the player, blame teammates, opponents, matchmaking, balance changes, and Riot Games using hyerbolic humor to cope and console.

## Status

Early concept stage. Development has not started yet.

## Planned Features

* Player-focused emotional support
* League of Legends–style trash talk
* Match and performance context
* Consistent comedic personality
